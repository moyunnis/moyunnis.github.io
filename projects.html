chistore active package repo · chinchilla team

a repository of packages developed by the chinchilla team. more programs are coming soon. репозиторий с пакетами, разрабатываемыми командой chinchilla team. скоро будут другие программы. — no, wait, no em dash: gitverse · github

rawgpt core local ai · ollama

a tool for local ai running on your server or computer using ollama. the honest trade is that it assumes you already run a model locally and are fine talking to it in a terminal. инструмент для локальных ии, работающих на вашем сервере или компьютере, с помощью ollama. честная оговорка: предполагается, что у вас уже локально крутится модель и вам нормально говорить с ней в терминале. gitverse · github

rawgpt-android active android client

rawgpt version for android phones. works only if you have a pc or server to do the actual thinking, the phone is just a thin terminal. версия rawgpt на телефоны с ядром android. работает только если у вас есть пк или сервер, который думает, телефон это просто тонкий терминал. gitverse · github · mansion · disroot

maximus active userbot · max messenger

userbot for the max messenger, based on maxli. юзербот для мессенджера max на базе maxli. github · mansion

uniland active language · cli and gui

a simplified programming language for writing cli utilities and gui programs. the honest trade is that simplicity here means you hit a ceiling fast on anything large, which is the point. упрощённый язык программирования для написания cli-утилит и gui-программ. честная оговорка: простота здесь означает, что на чём-то большом быстро упрёшься в потолок, в этом и суть. github · gitverse

the rest lives in the git services. but if even that doesn't interest you, you can read the story archive, or see where else to find me on the links page. остальное живёт в git-сервисах. но если и это тебе неинтересно, можешь почитать архив историй или посмотреть, где ещё меня искать, на странице ссылок.
